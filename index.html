Features

Six parts. One window.

From the first prompt to the final commit.

01 · Plan & track

See the plan, not the scrollback.

  • Mission Goalpinned on its own page
  • Task Boardtasks with live status
  • Plan Boarddependencies at a glance
  • Reporta clean summary at the end

vs. CLICLI plans scroll away. Here they stay.

THANATOS — Investigate · Fix plan

02 · Context & memory

Bring files in. Keep the context.

  • Attachmentsdrag in images, PDFs, code
  • Resumeclick a chat to pick up again
  • DiagramsMermaid renders inline
  • Auto-learnapprove what it remembers

vs. CLINo resume flags or hand-edited CLAUDE.md — just click.

THANATOS — Chat

03 · Agents that work for you

Hand off the loop.

  • Agent Rolespersonas on a Team page
  • Skillstoggle them in Settings
  • Workerskeep running while you switch
  • Dev Loopfix → verify → commit, repeat
  • Job Queuetrusted jobs, back-to-back

vs. CLIIn a terminal, you are the loop.

THANATOS — Team

04 · See what it builds

See it, test it, match the design.

  • Web Previewthe live page beside the chat
  • Browser testingreal clicks via Playwright
  • Tool Panelmaps and sortable sheets
  • Figmaframe to code, checked against design

vs. CLINo alt-tabbing to describe what you see.
